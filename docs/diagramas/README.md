# Diagramas entregables

Estos archivos son las vistas visuales del diseño de Room_911. Los SVG se pueden abrir directamente en el navegador o insertar en una entrega académica; los archivos Mermaid (`.mmd`) conservan la fuente editable.

El caso de uso general sigue la estructura de las imágenes entregadas en `Documentacion/`: cada módulo tiene su propio límite `Sistema Room_911`, conserva los nombres de módulo y reutiliza la numeración `CUxxx` por módulo.
