# Mockups

El mockup visual de las cuatro pantallas está en [mockups-room-911.svg](mockups/mockups-room-911.svg). Se diseñó con una estética de sala de control: fondo claro, azul de operación, verde para permiso y rojo para denegación.

Pantallas incluidas:

- Login por ID interno, sin contraseña.
- Panel de guardia con estado de credenciales y acción activar/suspender.
- Cronograma de secretaría con formulario de franja y agenda publicada.
- Simulador de torniquete con entrada/salida, medicamento y respuesta del motor.
